Kubernetes zum Anfassen

Große Webseiten laufen nicht auf einem Computer, sondern in vielen Kopien gleichzeitig. Kubernetes ist das Programm, das diese Kopien verwaltet. Hier kannst du ihm dabei zusehen und selbst eingreifen.

Kubernetes ausprobieren Daten als Karte erkunden

Was ist Kubernetes?

Stell dir ein Restaurant vor. Bei viel Andrang braucht es mehr Köche, fällt einer aus, muss sofort jemand einspringen, und am Eingang verteilt jemand die Gäste so, dass niemand ewig wartet.

Kubernetes ist dieser Restaurantleiter, nur für Programme. Man sagt ihm, was man haben will, zum Beispiel „drei Kopien von diesem Programm“, und er sorgt rund um die Uhr dafür, dass es so bleibt.

Firmen wie Spotify oder Zalando betreiben ihre Dienste so. Diese Vorführung läuft auf einem echten, nur sehr kleinen Kubernetes.

Pod
Eine laufende Kopie eines Programms.Im Restaurant: ein Koch.
Container
Das verpackte Programm, das überall gleich läuft.Die Kochmütze samt Rezept.
Service
Die eine Tür, durch die Anfragen kommen und verteilt werden.Der Empfang am Eingang.
Deployment
Die Beschreibung, wie viele Kopien laufen sollen.Der Dienstplan.
Cluster
Alle Computer, auf denen das läuft, zusammen.Das ganze Restaurant.

Das JSON-Astrolabium

Programme tauschen Daten in einem Format namens JSON aus, zum Beispiel eine Bestellung mit Kunde, Adresse und Artikeln. Solche Daten verzweigen sich wie ein Baum, und oft zeigt eine Stelle auf eine andere: „diese Bestellung gehört zu diesem Kunden“.

Das Astrolabium legt den Baum auf eine runde Karte mit besonderer Geometrie, wie in den Kreisbildern von M. C. Escher. In der Mitte ist alles groß, zum Rand hin immer kleiner, und trotzdem hat alles Platz. Was dich interessiert, holst du mit einem Tipp in die Mitte, drehst und zoomst mit Maus oder Fingern.

Es kann sogar die laufende Kubernetes-Vorführung selbst zeigen: welche Kopie zu welchem Programm gehört.

Astrolabium öffnen
So liest du die Karte
  • Gruppe von Einträgen, zum Beispiel ein Kunde
  • Liste, zum Beispiel alle Bestellungen
  • Einzelner Wert: Text, Zahl, ja/nein
  • Verweis auf eine andere Stelle
  • Wohin der Verweis zeigt (rot: ins Leere)

Für Neugierige: wie es gebaut ist

  • Ein echter Kubernetes-Cluster (k3s, gestartet mit k3d in Docker) mit drei Programmen: nginx für die Seiten, eine kleine Python-Schnittstelle in drei Kopien und Redis als gemeinsamer Speicher.
  • Keine eigenen Container-Images: Code und Seiten kommen als ConfigMap in den Cluster. Alles zusammen braucht rund 0,5 GB Platte und 700 MB Arbeitsspeicher.
  • Die Schnittstelle darf nur im eigenen Bereich (Namespace demo) Kopien auflisten, löschen und die Anzahl ändern, und zwar höchstens 6.
  • Das Astrolabium rechnet in der hyperbolischen Ebene: Jede Bewegung ist eine Möbius-Transformation, jede Linie ein Kreisbogen senkrecht zum Rand. Das Layout garantiert, dass sich Zweige nie überlappen.
